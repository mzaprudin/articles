## Навигация по репозиторию

Каждая статья оформлена в отдельной директории со всеми сопутствующими материалами:
- `README.md` — полный текст статьи с математическими выкладками, диаграммами и примерами кода.
- `habr.md` — подготовленная версия для публикации на Хабре с прямыми ссылками на ассеты.
- `assets/` — оригинальные векторные схемы (`.svg`) и оптимизированные растровые иллюстрации (`.png`, Retina 2×).
